## 入选规则

- 只收主榜分组：真伪与智商已按统一标准实测，7 天与 30 天可用率都达标，无警告和降智。
- 同一站有多个分组时，取综合分最高的一组代表这个站。
- 综合分按价格、可靠、真伪、智商、福利、计费加权。
- 不足 10 个就列实有数量，不补位。
- DeeDeeAI 为自营，不参与排名。

## 怎么读倍率

- 倍率是中转站相对官方价的计费系数：1x 约等于官方价，0.1x 约为官方价的一成。
- 实付倍率 = 分组倍率 ÷ 已核汇率。未核汇率不换算。缓存读写另算。
- 倍率低只说明便宜，还要一起看可用率和实测结论。
